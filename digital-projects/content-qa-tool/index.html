01 / The problem

Small data issues.
A messy publishing handoff.

A product catalog can look ready while still containing missing names, repeated SKUs, invalid prices or incomplete content. Before publication, those issues need to be found and made clear enough to correct.

Content QA Tool addresses that specific review step: take a catalog CSV, check it against explicit rules, and turn the findings into an actionable list. It supports review before publishing; it does not publish or edit the catalog.

02 / The approach

Import. Review. Hand off.

Keep the workflow focused, with a summary for orientation and a detailed explanation for every issue.

  1. Start with a CSV

    Load the bundled demo or import a UTF-8 file with the seven expected columns. Clear import messages explain format problems.

  2. Separate errors from warnings

    Required fields, duplicate SKUs, price and stock rules produce errors. Missing descriptions and missing or invalid image URLs produce warnings.

  3. Export only what needs attention

    Download an issues-only CSV with product row, SKU, field, severity and message. The original catalog stays unchanged.

03 / The working interface

Every finding has a reason.

The results identify the affected product and field, with written severity labels and a specific explanation. Product rows are numbered from 1, excluding the header and skipped blank rows.

Scroll the screenshot to inspect the results. With keyboard focus, use the arrow keys.

04 / Implementation

A small, transparent system.

The interface uses HTML, CSS and vanilla JavaScript. Papa Parse reads and generates CSV, while validation rules turn catalog issues into a downloadable report.

Files stay in the browser

Selected catalogs are processed locally, without uploading them to a server. Papa Parse loads from a CDN, so the application still needs an internet connection.

Explicit validation boundaries

SKUs are checked after trimming and ignoring case. Image URLs are checked for HTTP(S) format; the tool does not request images or verify that they exist.

Safe output

Imported values render as text. CSV export handles quoting and escapes spreadsheet formula strings across text columns.

Accessible review

Labeled controls, live import status, visible severity words and a keyboard-focusable results region support the workflow. Narrow screens can scroll the table sideways.
